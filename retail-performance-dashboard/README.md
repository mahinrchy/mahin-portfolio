# Retail Performance Dashboard

## Project Overview

This project presents an interactive Tableau dashboard analyzing retail sales, profitability, and regional business performance trends.

The dashboard was designed to help identify high-performing product categories, geographic sales patterns, and areas contributing to business losses.

---

## Tools Used

- Tableau
- Excel
- GitHub

---

## Dashboard Features

The dashboard includes:

- Regional sales analysis
- Profitability tracking
- Geographic sales visualization
- KPI monitoring
- Product category performance analysis

---

## Key Insights

### Technology Products Showed High Profit Variability

Technology categories generated strong profits but also demonstrated inconsistent performance across regions.

### Office Supply Categories Contributed Significant Losses

Several office supply subcategories consistently reduced overall profitability.

### Revenue Was Concentrated in Select Geographic Areas

A large percentage of sales performance was concentrated within a small number of states.

## Business Recommendations

- Reduce exposure to consistently unprofitable categories
- Focus expansion efforts on high-performing geographic regions
- Improve inventory planning for low-margin products
