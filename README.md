# Retail Performance Dashboard

This Tableau project analyzes retail sales, profitability, and geographic performance using the Sample Superstore dataset. The dashboard is designed to help identify profit drivers, loss areas, and regional trends to support data-driven business decisions.

---

## Key Insights
- Technology category shows the highest profit variability  
- Office Supplies drives the majority of losses  
- Sales trend is volatile but shows overall growth  
- Revenue is concentrated in a small number of states  

---

## Business Value
This dashboard enables stakeholders to identify underperforming categories, monitor sales trends over time, and focus on high-impact regions to improve overall profitability.
